## Listing content

**Title:** Godman Protocols SDK — Unified Multi-Agent Infrastructure Layer

**Category:** Infrastructure / Multi-Agent / Developer Tools

**Tagline:** All 7 Godman Protocols in one package. One import, production-ready multi-agent coordination.

**Description:**

The Godman Protocols SDK is the unified interface to all 7 open protocols for multi-agent AI infrastructure: PACT (trust), LAX (latency), SCORE (reputation), SIGNAL (events), SOUL (constitution), AMF (messaging), and DRS (resources).

Install one package instead of seven. Get cross-protocol types, helpers, and a live CLI demo that shows the full agent workflow in 20 seconds.

**What it gives your agents:**
- PACT mandate signing and revocation
- LAX latency-budget routing to the right runtime
- SCORE evaluation and verifiable reputation
- SIGNAL pub/sub event bus with delivery receipts
- SOUL constitutional rules and kill switches
- AMF signed, typed message envelopes
- DRS resource pool allocation and preemption
- Unified TypeScript types across all 7 protocols
- `npx godman-demo` — live 7-step workflow demo

**Zero external dependencies.** Node 20+ / Deno 1.40+ / Edge compatible.

**Works with:**
- OpenClaw Skills Registry (T1-T4 tiers)
- Claude Code, Cursor, Codex (plugin configs included)
- Kognai 5-tier model router (Nano → Local → Power → Cloud → Apex)
- x402 payment rail (Agent-to-agent transaction context)
