7 Protocols, One Standard

🤝

PACT

Mandate lifecycle for multi-agent coordination. Create, sign, verify, revoke mandates with coordination frames.

coordination
📨

AMF

Agent Message Format. Cryptographically signed envelopes for inter-agent communication with payload builders.

messaging
🛡

SOUL

Constitutional AI engine. Rule evaluation, kill switches, deny-first safety, and audit trails.

safety
⚡

LAX

Latency-aware execution. Budget tracking, probe timing, SLA enforcement, and intelligent task routing.

performance
📊

SCORE

Reputation and evaluation. Rubric-based scoring, weighted reputation aggregation, and audit logs.

reputation
📡

SIGNAL

In-memory event bus. Pub/sub with topic-glob matching, idempotency dedup, and delivery receipts.

events
📦

DRS

Dynamic Resource Scheduling. Pool management, allocation, preemption, and automatic expiry.

resources

One SDK, All Protocols

The unified SDK re-exports all 7 protocols. Import once, build with everything.
